### Тесты:

1. **test_product_init**:
   Тестирует корректность инициализации объекта `Product`. Проверяет, что продукт, созданный в фикстуре `product_one`, имеет правильные значения для атрибутов `name`, `description`, `price` и `quantity`.

   - **Ожидаемые результаты**:
     - `name` продукта должно быть равно `"Samsung S24 Ultra"`.
     - `description` продукта должно быть равно `"Замечательный новый смартфон Samsung S24 Ultra"`.
     - `price` продукта должно быть равно `100000.50`.
     - `quantity` продукта должно быть равно `50`.

2. **test_add_new_product**:
   Тестирует метод класса `new_product`, который создает новый экземпляр класса `Product` из переданных данных. Проверяется, что новый продукт корректно инициализируется с помощью словаря.

   - **Ожидаемые результаты**:
     - Новый продукт должен иметь правильное имя `"Samsung Galaxy S24"`.
     - Количество продукта должно быть равно `25`.

3. **test_price_lower_than_zero**:
   Тестирует работу сеттера `price` в классе `Product`. Проверяется, что цена продукта может быть установлена, но не может быть равна нулю или отрицательной.

   - **Ожидаемые результаты**:
     - После изменения цены на положительное значение (например, `175000`), цена должна быть установлена правильно.
     - При попытке установить цену в `0` или отрицательное значение (например, `0`), цена не должна измениться.

4. **test_category_init**:
   Тестирует корректность инициализации категории продуктов. Проверяется, что объект категории, созданный в фикстуре `category_one`, имеет правильные значения для атрибутов, а также что список продуктов категории правильно заполняется.

   - **Ожидаемые результаты**:
     - `name` категории должно быть равно `"Смартфон"`.
     - `description` категории должно быть равно `"Замечательный новый смартфон"`.
     - Количество продуктов в категории должно быть равно `2`.
     - Количество категорий и продуктов должно быть корректно рассчитано с использованием соответствующих методов и атрибутов.
     - Продукты, находящиеся в категории, должны быть корректно возвращены через геттер `products_list`.

5. **test_add_product**:
   Тестирует метод `add_product` для добавления нового продукта в категорию. Проверяется, что добавление нового продукта увеличивает количество продуктов в категории, а новый продукт корректно появляется в списке продуктов.

   - **Ожидаемые результаты**:
     - После добавления нового продукта длина списка продуктов в категории должна быть равна `3`.
     - Новый продукт должен быть корректно добавлен в список, и его `name` должно быть равно `"Playstation 5 Slim"`.

6. **test_str_presentation**:
   Тестируется строковое представление категории.

   - **Ожидаемые результаты**:
     - Строковое представление категории должно представлять собой `Смартфон, количество продуктов: 60 шт.`.
